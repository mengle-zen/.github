### 이름에 담은 뜻

**맹글다**는 제주도 말로 ‘만들다’, **~젠**은 ‘~하려고’라는 뜻의 말입니다. 우리에게 **맹글젠**은 “만들자”라는 마음에 가까운 이름입니다. 영문 표기 **Mengle.zen**의 `zen`에는 차분히 몰입하는 즐거움과 새로운 것을 만들어 보는 말장난도 담았습니다.
